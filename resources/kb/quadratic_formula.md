# Quadratic Formula

For any equation of the form `ax^2 + bx + c = 0` where `a != 0`, the roots are:

x = (-b +/- sqrt(b^2 - 4ac)) / 2a

## Discriminant

The term `D = b^2 - 4ac` is called the discriminant:

- `D > 0` — two distinct real roots
- `D = 0` — one repeated real root
- `D < 0` — two complex conjugate roots

## Worked Example

Solve `2x^2 - 4x - 6 = 0`.

- a = 2, b = -4, c = -6
- D = (-4)^2 - 4(2)(-6) = 16 + 48 = 64
- x = (4 +/- 8) / 4, so x = 3 or x = -1
